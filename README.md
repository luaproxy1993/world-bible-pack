# World Bible Pack

Pictures from a **text** World Bible: portraits, a playable-window map, location plates, props.

Requires `/world-bible` first.

```text
/world-bible-pack
/world-bible-pack ~/worlds/the-cancel
```

Writes `{world}/pack/` and `pack/pack.json`. Does not rewrite the bible.

## Install

```bash
npx skills add luaproxy1993/world-bible-pack -y
```

World Bible (text):

```bash
npx skills add luaproxy1993/world-bible -y
```

Current: **1.0.0**.
